TYPES

임플란트 종류

상태와 생활에 맞는 방법을 전문의와 상담하세요.

당일 발치 후 즉시 식립네비게이션고난도자가혈(PRF)재수술틀니 임플란트

01

당일 발치 후 즉시 식립

바쁜 현대인을 위한 맞춤 시술

발치 당일 바로 임플란트를 식립해 수술 횟수와 치료 기간을 줄입니다. 비절개 방식으로 출혈이 적습니다. 잇몸 염증이 심한 경우에는 어려울 수 있습니다.

이럴 때 권해드려요

  • 치과 방문이 어려운 경우
  • 치료 기간을 줄이고 빠른 시술을 원하는 경우
  • 빠른 회복을 원하는 경우
  • 적은 통증을 원하는 경우

02

네비게이션 임플란트

첨단 시뮬레이션으로 보다 높은 정확도

3D 컴퓨터 모의 수술로 개인별 맞춤 계획을 세우고 부작용 우려를 줄입니다. 최소 절개로 통증 부담을 줄입니다.

이럴 때 권해드려요

  • 질환이 있거나 고령인 경우
  • 임플란트가 여러 개 필요한 경우
  • 오랜 시간 치료가 힘든 경우
  • 절개가 적고 통증이 적은 치료를 원하는 경우

03

고난도 임플란트

풍부한 경험으로 안정적인 결과

정밀검사와 철저한 치료계획으로 1:1 맞춤 시술을 진행합니다. 질병이나 복용 중인 약물이 있다면 꼭 말씀해 주세요.

이럴 때 권해드려요

  • 전신질환이 있거나 약물을 복용 중인 경우
  • 당뇨가 있는 경우
  • 고혈압 및 기저질환이 있는 경우
  • 골다공증이 있는 경우

04

자가혈(PRF) 임플란트

내 혈액에서 얻은 성장인자로 회복을 돕습니다

PRF(Platelet Rich Fibrin)는 혈액에서 백혈구·혈소판을 추출해 고농도 성장인자를 얻는 기술입니다. 자가 혈액을 사용해 거부반응 우려가 적고, 잇몸뼈 형성을 도와 회복 기간 단축에 도움을 줍니다.

이럴 때 권해드려요

  • 회복이 느린 노년층
  • 질환이 있는 경우
  • 출혈이나 붓기가 걱정되는 경우
  • 부작용 우려를 줄이고 싶은 경우

05

임플란트 재수술

재수술은 경험 많은 의료진에게

사고·외상, 치주염, 음주·흡연, 관리 미숙, 재료 문제 등으로 임플란트를 다시 해야 하는 경우 정밀 진단 후 재수술을 계획합니다.

이럴 때 권해드려요

  • 임플란트 뿌리에 문제가 생겼을 때
  • 주변에 염증이 발생한 경우
  • 보철물에 문제가 발생한 경우
  • 수술 실패로 탈락한 경우

06

틀니 임플란트

치아의 수명을 연장하기 위한 노력

임플란트를 식립한 뒤 틀니를 연결해 기존 틀니의 불편함을 개선합니다. 유지력이 뛰어나고 여러 개의 임플란트보다 경제적입니다.

이럴 때 권해드려요

  • 틀니가 아프고 불편한 경우
  • 다수의 치아를 치료해야 하는 경우
  • 임플란트 비용이 부담될 때
  • 오랜 틀니 사용으로 새 틀니가 필요할 때

*모든 시술은 부작용을 동반할 수 있으므로 의료진과의 상담이 필요합니다.
