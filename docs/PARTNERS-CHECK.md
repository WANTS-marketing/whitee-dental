## 데이터 (`SITE.partners.list`, CSV 순서 그대로)
| 필드 | 내용 |
|---|---|
| `name` | CSV '기관명(사이트 표기)' |
| `date` | 협약일자(엑셀) — 없으면 `''` |
| `branches` | 로고 시트에 로고 위치가 있는 지점 `['masan', 'changwon']` — 없으면 `[]` |
| `logo` | `assets/images/partners/` 안 파일 이름 — 없으면 `''` (글자 타일) |

- 화면에는 이름(또는 로고)만 표시. 협약일자·지점은 데이터에만 둠. 혜택 문구('제휴 할인' 등)는 넣지 않음
- 큰 숫자 = `list` 개수 자동(지금 69)
- 강조 카드 3개(부산대학병원 협력 · 경찰자문 · 방송출연)는 그대로 유지 (기존 홈페이지 sub06_01 기준)

## 고치는 법
- 기관 추가·삭제: `site-data.js` `partners.list` 그 줄만 추가/삭제 → 메인 숫자도 자동으로 바뀜 (CSV 도 같이 고쳐 두기)
- 로고를 받으면: `assets/images/partners/` 에 webp 로 넣고 그 줄 `logo: '파일이름.webp'` — 글자 타일이 로고로 바뀜
- 흐르는 2줄 배치는 자동(`common.js` renderSiteBlocks): 로고 타일·글자 타일을 각각 번갈아 두 줄에 나누고, 줄 안에서 글자 타일을 로고 사이에 고르게 섞음
- 섹션을 다시 숨기려면 `index.html` `#screen-partners` 에 `hidden` 추가 (오른쪽 섹션 점도 자동으로 빠짐)
